## Test

Find your adress IP on your android phone
1. Va dans Paramètres > Wi-Fi.
2. Clique sur le réseau Wi-Fi connecté (le nom du réseau).
3. Regarde dans les détails ou paramètres avancés :
    → Adresse IP : quelque chose comme 192.168.x.x.

Après tu peux envoyer des messages UDP via la commande nc
nc -u [ip_android] 2000
